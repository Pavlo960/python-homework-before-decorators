# Домашнє завдання: перед декораторами

5 обов'язкових задач + 2 бонусні (з позначкою "star" у назві папки).

## Як здати

1. Зроби Fork цього репозиторію собі на GitHub
2. Склонуй свій форк локально: git clone <посилання на твій форк>
3. Розв'яжи задачі - редагуй файл task.py у кожній папці
   (заміни рядок pass на свій код)
4. Перевір рішення: зайди в папку задачі і виконай
   python test_task.py
   Якщо все правильно - побачиш "All tests passed! ✅"
5. Заком'ять і запуш зміни у свій форк:
   git add .
   git commit -m "Розв'язав домашнє завдання"
   git push
6. Надішли мені посилання на свій форк

## Порядок виконання

Рекомендую розв'язувати по порядку від 01 до 05 - складність поступово
зростає. Бонусні задачі (06, 07) - лише якщо є час і хочеться додаткового
виклику, вони не впливають на основну оцінку.

## Що можна використовувати

Усе, що ми проходили: змінні, умови, цикли, списки/кортежі/словники/set,
функції з параметрами й return, *args, f-strings.

Задача 06 - на closures (nonlocal), яку ми недавно розбирали на прикладі
рахунку балів у вікторині.

Не потрібно (і поки що не варто) використовувати: класи, декоратори,
list/dict comprehensions, try/except, lambda.
